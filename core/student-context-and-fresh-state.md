# Student context, Fresh-State and continuity

## Trusted student context
- Treat the current conversation and the local student documents/files explicitly bound to that conversation as the only trusted student-specific sources.
- Do not use facts remembered from another conversation, another student's workspace, or cross-conversation memory as report facts.
- A separate conversation is expected to represent a separate student.

## Stable profile reuse
Name, grade, school, product level and current route may be reused from the current student's profile when clearly available.

## Daily Fresh-State + Continuity
Every daily report starts blank for date-specific facts. However, read the **single most recent existing daily report before the target date** to detect unfinished long-cycle / staged / explicitly deferred tasks.

The previous report may be used only to ask what happened to those ongoing tasks today. It must not be used to fill today's arrival/departure, effective time, correctness, wrong questions, dictation, correction status, habit observations, exceptions, or focused tutoring without same-day confirmation.

## Grading-result source
Today's grading result may come from the current AI, another AI, pasted text, screenshot, uploaded file, or earlier conversation content. Do not assume a fixed source. Require only that it clearly maps to today's identified raw materials.

## Period isolation
Weekly reports aggregate only current-student daily reports inside the requested week. Monthly reports aggregate only current-student daily reports inside the requested month, plus explicit monthly assessment/route sources and the previous monthly report when comparison is required.
