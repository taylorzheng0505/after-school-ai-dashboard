01｜文档权威性

使用原则：若旧产品手册、旧SOP、旧看板、旧会议口径与本文件冲突，以本文件为准。任何后续产品规则变更，先更新Source of Truth版本，再同步修改SOP、看板和Skill，避免多版本漂移。

02｜L2 / L3 产品边界

L2｜学习执行管理

替代家长完成日常学习执行事务，不替代学科老师。

  • 核任务、备材料、拆任务、排优先级、管时间
  • AI/答案辅助基础批改
  • 原始错题留痕、巡班快速答疑、确认订正
  • 日报 + 周报
  • 不做：系统教学、错因诊断、能力诊断、举一反三、月报

L3｜学业管理

继承L2执行底座，再增加固定教学与周期性问题解决。

  • 每周4×30min专项辅导：Math 2 + English 2
  • 日报结构化错题、周度重复问题识别、月度深度分析
  • 每月模拟测试 + 月报 + 家长沟通
  • 按路线显示传统 / 国际 / 转轨管理信息
  • 期中/期末冲刺周

03｜L2 / L3 共用现场执行底座

L2、L3自习现场不做两套流程，优先按年级和运营效率组织学生。

环节统一规则
到校记录到校/离校、有效学习时长、路线状态与特殊事项。
任务识别督导与学生共同核对CJ/学校作业清单/班级通知，不接受“我今天没作业”式模糊口述。
材料判断打印/复印需求；学校正式作业原件不直接由机构教师批改或涂改。
任务管理拆任务、排优先级、设时限；每项任务记录截止日期。普通当日作业可记“当日”；长周期任务记录真实DDL与当天进度。
完成学生自主执行，督导管理进度、节奏、纪律和求助方式，不做知识教学。
批改督导借助标准答案/AI判断对错；开放题/识别不确定交教师复核。
错题订正前保留原始图片。AI可裁切/整理，不得以OCR重写文本替代原图。
快速答疑巡班老师处理当下知识疑问。单生当日总时长原则上按约20分钟以内做内部产能管理，不作为固定课时承诺。
离校当日应闭环的任务与错题尽量在离校前完成订正；异常必须真实记录。

04｜L2 固定规则

错题只留痕原图 + 科目 + 任务来源/题号 + 订正状态；不要求知识点或错因分类。
只有日 / 周看板周报由本周日报自动汇总，督导事实复核；无L2月报。
不做完成率误导长周期Project/阅读只记录当天推进，不用一个总完成率把“未到截止日”写成未完成。

05｜L3 固定规则

最重要变更：专项辅导为每周4次×30分钟，共2小时；Math 2次 + English 2次；当周必须完成，不结转、不累计。

排课与班型

  • 机构主动排满4次，不等待家长决定何时消课
  • 周末后不形成下周余额；未完成视为本周异常
  • 标准班型1V3；启动期可按实际人数临时1V1/1V2
  • 场地不写死：可独立教室，也可同空间错峰；关键是教学时段与日常自习区隔

教学内容

  • 来源于近期错题、反复问题、薄弱知识点、Quiz/考试/月测
  • 不单独另开一门完整新课
  • 可以做举一反三、同类题巩固和迁移训练
  • 当天上课必须形成简短教师反馈并进入日报

06｜L3错题系统的三层逻辑

时间层级留下什么用途
日原图 + 题型 + 涉及能力/知识点 + 错误表现 + 错因 + 订正状态把单次错误结构化，给后续教师和AI留下足够上下文；不因单题形成长期结论。
周重复题型、重复能力问题、反复错误机制、改善信号、下周重点从零散错题中识别“重复信号”，决定下周专项辅导关注点。
月能力问题地图、深度错误链、教学动作、干预效果、上月对比形成真正可用于家长沟通和下一阶段教学的稳定判断。
责任分工：督导负责原始数据与流程触发；AI做预处理/汇总；教师通过答疑和专项反馈校正专业判断。家长端只展示最终“错因/能力问题”，不展示“AI说/学生说/老师说”。

07｜五个家长看板的固定结构

看板必须包含禁止/注意
L2日报路线、到离校、任务Checklist（含截止日期）、每任务核对结果、错题/听写原图、执行备注、可观察习惯行为不做错因诊断；不强调听写由什么Agent完成
L2周报出勤/时长、每日执行、分科客观正确率、错题/听写汇总、持续任务及DDL/跨周待办、习惯观察由日报自动汇总；不做学术分析；无月报
L3日报L2日报全部 + L3错题结构化 + 当天专项辅导教师反馈/“今日无专项辅导”原图不可被AI重画取代
L3周报L2周报底座 + 重复问题初步分析 + Math/English本周应上/已上/完成状态 + 课次反馈禁止余额、结转、累计剩余
L3月报上月趋势对比、深度错题分析、教学动作、干预效果、月测、路线管理、下月重点AI不得补造不存在的数据；月测和最新路线进度需额外输入

08｜AI与数据生成原则

AI生成

  • 日报模板化输出；督导必须提供足够准确的事实信息
  • 周报由日报一键汇总
  • L3月报由日/周数据 + 月测 + 路线进度一键整合
  • AI可以统计、归类、发现重复模式，但不得在缺少证据时补造错因、成绩或路线进度

数据沉淀

  • 家长HTML看板展示的信息全部可见，不设计家长不可见的隐藏字段
  • 错题以原图作为事实证据
  • 学生日报、周报、月报、错题资料应进入有权限控制的共享档案
  • 轮班督导必须能接续同一学生历史信息，避免数据留在个人对话里

09｜落地支撑系统

教材与教研

  • 收集贝赛思各年级教材、练习册、测评资料
  • 教师按学科熟悉体系，AI辅助抽取知识框架
  • 建立阶段/月度模拟测试题库
  • 遇到巡场教师陌生题型可提前把错题发给老师预处理

共享档案

  • 优先使用企业微信微盘/组织内共享盘
  • 按学生建立文件夹并设置最小必要权限
  • 沉淀错题、日报、周报、月报等运营资料
  • 原则：尽量减少人工重复编辑，把人留给判断、教学与家长沟通

10｜暂不固化 / 后续验证

事项当前状态
期中/期末冲刺周具体形式待验证 可能包含知识点梳理、刷题、错题复盘等，尚不固化。
L3专项辅导固定星期几待排班 只锁定每周Math 2 + English 2，当周完成；具体日期按师资产能排。
专项辅导是否扩科暂不扩 v1.0只认Math/English；未来扩科需先更新Source of Truth。
企业微盘最终权限方案待管理员确认 共享原则已定，具体权限配置待落地。
