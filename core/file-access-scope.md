# 文件读取范围 v1.6

本文件定义 6 个工作流的默认数据读取白名单。目标是避免 AI 为“确保完整”而扫描整个学生工作区，并优先让机器读取轻量结构化数据，而不是重复解析重型HTML。

## 作业批改
只读取督导明确指定的当次原始作业/试卷。输出 `grading-data.json + crops/ + grading-report.html`。

## L2 / L3 日报
默认允许读取：
1. 当前学生稳定档案；
2. 目标日期前最近一份日报，仅用于未完成长期任务连续性；
3. 今日标准作业批改包中的 `grading-data.json` 与其明确引用的 `crops/`；
4. 仅对未被标准批改包覆盖的材料，读取督导明确指定的今日原始作业/试卷；
5. 今日执行信息。

日报正常路径不解析重型 `grading-report.html`。上一份日报不得提供今日时间、正确率、错题、习惯、异常或专项辅导等当日事实。

## L2 / L3 周报
优先读取当前学生、目标周范围内的 `daily-data.json`。只有某日JSON缺失时，才读取该日HTML作为兼容回退。

不扫描原始作业/试卷、独立错题库、月报或其他周；不重新裁图。周报通过 `weekly-data.json` 聚合后由 renderer 输出最终HTML。

## L3 月报
优先读取当前学生、目标月份内的 L3 `daily-data.json`；另读取明确提供的本月月测/模拟测试、路线进度，以及需要环比时的上月 `monthly-data.json`。只有对应JSON缺失时才读取同周期HTML作为兼容回退。

不扫描原始作业/试卷、独立错题库或无关月份；不重新裁图。月报通过 `monthly-data.json` 聚合后由 renderer 输出最终HTML。

## 缺失处理
若白名单内缺少必要资料，索取具体信息或路径；不得自行扩大扫描范围。
