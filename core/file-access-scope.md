# 文件读取范围 v1.4

本文件定义 5 个看板工作流的默认数据读取白名单。目标是避免 AI 为“确保完整”而扫描整个学生工作区。

## L2 / L3 日报
只允许默认读取：
1. 当前学生稳定档案；
2. 目标日期之前**最近一份实际存在的日报**，且仅提取未完成长期任务/持续任务；
3. 督导提供或明确定位的今日标准作业批改HTML（优先级高于原始作业）；
4. 仅对未被标准批改报告覆盖的材料，读取督导明确指定的今日原始作业、试卷文件或文件夹；
5. 督导提供的本次批改结果，来源不限，可为文字、截图、文件、其他AI输出或本对话前序；
6. 今日执行信息。

不得默认扫描周报、月报、历史错题库或整个历史日报目录。上一份日报只用于长期任务连续性，不能继承昨日时间、错题、正确率、习惯、异常或专项辅导等当日事实。

如果已有完整标准批改HTML并能对应今日作业，日报不重复批改、错题分析或裁剪；直接读取报告中的结构化数据和逐题证据图。没有标准报告的材料才进入日报原有批改/裁剪路径。

## L2 / L3 周报
只读取当前学生、指定周日期范围内的日报。先按日期/文件名筛选，再读命中文件。

不扫描原始作业/试卷，不扫描独立错题库，不扫描月报或其他历史周；错题、听写、长期任务和习惯均从日报汇总。周报不重新裁剪原始作业。

## L3 月报
只读取当前学生、指定月份内的日报；另读取督导明确提供或定位的本月月测/模拟测试、路线进度，以及需要环比时的上月月报。

不扫描原始作业/试卷，不扫描独立错题库，不扫描无关月份；月报不重新裁剪原始作业。

## 缺失处理
如果白名单内缺少必要资料，向督导索取具体信息或明确路径；不要自行扩大扫描范围。
