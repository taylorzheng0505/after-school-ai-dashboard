5个看板 Skill 信息采集与交互规范 v1.3

课后托管 L2 / L3｜一线督导调用 AI 生成日、周、月看板的统一交互协议
版本 v1.3 更新：2026-09-02 适用：5个看板 Skill 上位规则：L2/L3 Source of Truth v1.0
定位统一交互数据继承 L2日报L2周报 L3日报L3周报L3月报 校验规则一线速查

01｜文档定位

本文件不重新定义产品内容，而是规定 AI 在真实调用时“怎样向督导索取信息、怎样判断信息是否足够、怎样追问、怎样继承历史数据”。

目标 1｜一轮尽量收齐AI第一次回复就列清本次全部资料需求，允许督导用自然语言、截图、照片、HTML混合提交。
目标 2｜最多一次补问AI先审核完整性；只有关键缺项才进行一次定向追问，不逐项“审讯式”提问。
目标 3｜越往后越少手填周报只汇总目标周日报；月报只汇总目标月日报并补月测/路线；日报仅定向读取最近一份日报以追踪长期任务。
硬原则：AI不得为了“把报告写完整”而补造事实。没有提供、无法从前序看板推导、证据不足的信息，必须标记为“未提供 / 暂无法判断 / 数据不足”，或在生成前进行关键追问。

02｜五个 Skill 共用的统一交互流程

① 识别看板类型→② 读取当前已有资料→ ③ 一次性索取缺失资料→④ 自动解析/计算→ ⑤ 完整性审核→⑥ 最多一次补问→⑦ 生成看板

统一状态判断

🟢 信息完整关键数据齐全，直接生成；非关键字段也有充分信息。
🟡 可生成存在非关键缺项，但不会影响报告真实性；用“未提供 / 暂无记录”处理，不阻断生成。
🔴 暂不生成缺少会导致报告失真、错配或无法核验的关键数据；只追问这些缺项。
交互体验要求：AI列清单是为了告诉督导“需要什么”，不是强迫督导按固定表格填写。督导可以直接用自然语言回复，AI负责拆解与结构化。

03｜数据继承与信息来源优先级

优先级信息来源使用规则
1本次督导明确提供的事实优先级最高；如与旧报告冲突，以本次明确更新为准。
2本周期已生成的前序看板日报仅读取最近一份历史日报的未完成长期任务；周报读取目标周日报；月报读取目标月日报。
3学生固定档案姓名、年级、路线等稳定信息可复用；发生变化时必须更新。
4原始图片 / 测试材料 / 教师反馈作为错题、月测、专项辅导等事实证据。
禁止AI常识性猜测不得用“通常”“看起来”“应该”替代缺失的学生事实。
不重复索取：如果当前对话/工作区中已经有可靠的学生姓名、年级、路线、前序日报/周报，AI应直接复用，不再机械追问。

04｜Skill 1：L2 日看板｜信息采集规范

L2日报是后续周报的数据源，因此要求“事实完整、任务清楚、错题有原图、行为可观察”，但不要求督导做学术诊断。

信息组督导需提供AI可自动处理完整性级别
学生与日期姓名、年级、日期、当前路线（传统/国际/转轨）若已有学生档案可继承关键
时间到校、离校；有效学习时长若现场已有记录可直接给可根据可靠的起止/休息记录计算；不能只用“离校-到校”默认等于有效学习关键
今日任务科目、具体任务、当天完成情况；长期任务写当天推进；顺延写原因把自然语言拆成Checklist；不生成“总任务完成率”误导长期任务关键
客观核对可核对任务的总题数/正确数，或直接给批改结果自动计算正确率；开放题/Project不强算正确率有则必填
错题/听写原始图片；来源/题号；是否已答疑、是否已订正可裁切整理图片；不得OCR重绘代替原图有错则关键
学习过程与习惯1–3条可观察行为归入自主启动、专注/节奏、任务管理、求助方式、复盘等维度必填
其他异常迟到、早退、材料缺失、情绪/身体状态、特殊安排等；无则写“无”整理为家长可见备注无可写无

AI 第一轮标准询问

推荐回复模板｜L2日报
好的。请一次性把今天的信息发给我，文字、截图、作业照片混合发送都可以，不需要提前整理成表格。 1）学生与时间：姓名、年级、日期、当前路线；到校、离校、有效学习时长。 2）今日任务：今天所有任务分别是什么；每项完成到哪里；可客观核对的任务请给总题数和正确数；Project/阅读等长期任务写今天推进到哪里；有顺延请说明原因。可以直接上传CJ/任务清单。 3）今日错题与听写：请提供今日原始作业/试卷或明确文件路径，并提供本次批改结果（可来自其他AI、截图、文件、复制文字或本对话前序）。确认错题后必须逐题裁剪原始证据；并说明是否已答疑、是否已订正。 4）学习过程与习惯：请给1–3条今天真实看到的行为，例如“到校后5分钟内自主启动”“综合题先独立尝试10分钟再求助”“后半段两次提醒后恢复任务”。不要只写“认真/努力”。 5）其他情况：迟到、早退、材料缺失、特殊安排或需要家长知道的事项；没有写“无”。 你可以直接用自然语言回复，我会自动整理并检查是否缺关键资料。

必须追问的情况

  • 有错题/听写错误，但缺原始图片。
  • 任务只写“数学、英语都做了”，无法形成具体Checklist。
  • 没有说明任务完成状态或长期任务当天推进情况。
  • 学习过程与习惯只有“认真、努力、状态不错”等不可观察评价。
  • 到/离校或有效学习数据关键缺失且无法从可靠记录计算。

05｜Skill 2：L2 周看板｜信息采集规范

周报原则上不让督导重新手填本周数据，而是读取本周日报后自动汇总。

输入要求AI动作
关键 本周L2日报提供本周所有实际到校日的日报HTML/内容汇总出勤、时长、每日任务、分科正确率、错题、听写、持续任务、习惯观察
需确认 缺失日期若自然周工作日/约定托管日没有日报，说明“未到校 / 请假 / 节假日 / 日报缺失”区分正常未到校与数据缺档
可选 本周特别事项日报无法完整体现的学校活动、考试周等补入周度备注
推荐回复模板｜L2周报
可以。请一次性提供本周全部L2日报（HTML或直接上传文件均可）。 如果本周某个原本应到校的日期没有日报，请同时说明该日属于： A. 未到校/请假； B. 节假日/机构不营业； C. 日报缺失，需要补资料。 除此之外无需重新总结本周数据，我会从日报自动生成周报。
完整性校验：如果只收到4份日报，AI不能默认“本周只来4天”，必须先确认第5天是未到校还是资料缺失。

06｜Skill 3：L3 日看板｜信息采集规范

完整继承L2日报全部输入，再增加“结构化错题所需证据”和“当天专项辅导”。

继承规则：L3日报必须先满足L2日报的全部基础信息要求，不能因为增加了学业分析而丢掉到离校、任务执行、习惯观察等基础字段。

L3新增输入 A｜结构化错题

督导提供事实AI负责结构化禁止
原始错题图片、题号/来源、正确答案或订正结果（有则提供）题型、涉及能力/知识点、错误表现用重绘题目替代原图
学生当时卡在哪里/如何作答（有则提供）结合证据形成“错因”仅凭一道题强行形成长期能力结论
巡班老师答疑时发现的关键问题（有则提供）提高错因判断精度证据不足时假装确定
订正状态记录是否闭环未订正写成已掌握
证据不足的处理：允许写“本次表现为……，是否属于稳定问题需继续观察”或“当前证据不足，暂无法判断深层原因”。不要为追求完整而编造错因。

L3新增输入 B｜今日专项辅导

科目需要提供没有上课时
Math是否上课、30min课次、主要内容、教师课后反馈明确写“Math今日未安排专项辅导”
English是否上课、30min课次、主要内容、教师课后反馈明确写“English今日未安排专项辅导”
推荐回复模板｜L3日报
好的。L3日报会完整继承L2日报的信息，所以请先一次性提供：学生/日期/路线、到离校与有效学习时长、今日全部任务及核对结果、错题/听写原图、学习过程与习惯、其他异常。 另外请补两类L3信息： 6）错题补充信息：每道错题尽量提供原始图片、正确答案/订正结果、学生当时卡在哪里或说了什么、巡班老师答疑时发现的关键问题。你不需要自己填写“题型/能力/错因”，我会根据证据结构化；证据不足时不会强行下结论。 7）今日专项辅导：请分别说明Math和English今天是否上30分钟专项辅导。如有，请提供主要内容和老师课后反馈；没有请直接写“Math无 / English无”。

07｜Skill 4：L3 周看板｜信息采集规范

读取本周L3日报自动汇总，并额外执行“每周Math 2次 + English 2次”的交付校验。

输入要求AI自动处理
关键 本周全部L3日报所有实际到校日继承L2周报全部汇总 + 错题重复信号 + 习惯观察
强校验 Math专项辅导本周应为2次×30min统计“应上2 / 已上X / 是否完成”
强校验 English专项辅导本周应为2次×30min统计“应上2 / 已上X / 是否完成”
补充 教师反馈若某次日报漏记，可单独补充补齐课次记录与周度摘要
禁止旧逻辑：不得出现“上周结转 / 本周新增 / 本周剩余 / 累计余额”。课次当周清零，不结转。
推荐回复模板｜L3周报
请一次性提供本周全部L3日报。如果某次Math/English专项辅导没有写进日报，请同时补充该次课程的日期、30分钟时长、主要内容和教师反馈。 我会自动汇总本周执行数据、错题重复信号、学习习惯，并校验： - Math：本周应上2次； - English：本周应上2次。 如果识别到某科不足2次，我会先确认是“资料漏传”还是“本周确实未完成”，再生成周报。

专项辅导不足时的唯一补问模板

示例
我目前从本周资料中识别到： Math 1/2次，English 2/2次。 请确认Math少1次属于： A. 实际已上，但日报/教师反馈未上传； B. 本周确实只完成1次。 如果是A，请补充该次课程信息；如果是B，请告诉我未完成原因，我会在周报中如实记录。

08｜Skill 5：L3 月看板｜信息采集规范

月报不要求督导重新回忆整个月。主数据直接汇总目标月份内的L3日报，督导只补“月测、路线更新、特殊事项”等无法从日报获得的新信息。

输入资料用途缺失处理
关键 本月L3日报月度执行、专项辅导、错题重复问题、习惯变化只读取目标月份内的日报；缺失关键日期时再追问
继承 上月L3月报环比趋势、上阶段重点、干预效果首次月报则标记“首月，无上月对比”
关键 本月模拟测试日期、成绩、分项表现、与日常记录对应无数据不得编成绩；若本月应测未测，记录异常原因
关键 路线最新进度传统/国际/转轨管理及升学节点无变化可明确写“本月无更新”；不得沿用旧风险当成新变化
可选 本月特殊事项长假、考试周、重大课程调整等没有可写“无”
推荐回复模板｜L3月报
好的。请一次性提供这个月的“月报资料包”： 1）本月日期范围内的L3日报；如本地日报文件夹可读取，只需确认月份。 2）上个月L3月报，用于做环比；如果这是第一次生成月报，直接写“首月”。 3）本月模拟测试：测试日期、试卷/成绩、分项结果或老师说明；可以直接上传照片或报告。 4）本月路线进度：当前路线是否变化；是否新增校内考试、MAP/RIT、转轨、择校/升学节点等。没有变化请写“无更新”。 5）本月特殊事项：长假、考试周、长期请假、课程调整等；没有写“无”。 其余月度数据我会从当月日报自动汇总，不需要你重新总结，也不会扫描原始试卷或独立错题库。

月报证据强度规则

情况可以怎么写不可以怎么写
只出现1次错误“本月出现1次相关错误，暂未形成稳定重复信号”“该能力明显薄弱”
多周重复出现可进入“能力问题地图”，并标注趋势忽略时间跨度只报总次数
已有教学干预对比干预前后同类任务/正确率/出现次数仅因为上过课就写“已改善”
上月口径不同说明“口径不同，暂不直接环比”强行计算变化率
月测缺失“本月月测数据未提供/未完成”根据日常作业推测测试成绩

09｜全局校验与防错规则

数据计算规则

  • 正确率只统计有标准答案、可客观核对的题目。
  • 作文、Project、阅读时长、开放任务不强行计入正确率。
  • 题目错题与听写错误分开统计，避免口径混淆。
  • 有效学习时长不能仅用“离校－到校”默认计算，除非已明确包含/扣除休息。
  • 长周期任务记录“当天推进”，不把未到截止日写成未完成。

表达与证据规则

  • 学习习惯必须写可观察行为，不写“认真、努力、态度好”。
  • L2不输出错因、能力诊断或专项训练建议。
  • L3错因证据不足时允许“待观察 / 暂无法判断”。
  • 原始错题图片是事实证据，AI不得重画后替代。
  • 家长端不展示“AI说 / 学生说 / 老师说”，统一输出最终记录。

生成前必须通过的 8 项检查

#检查项通过标准
1学生身份姓名/年级/日期或周期无错配
2路线存在有效路线信息，或已明确本期无变化
3任务每项任务有具体内容和状态，长期任务有当天/本周推进
4客观数据正确率分母清楚，不把开放任务纳入
5错题证据有错题时有原图；订正状态真实
6学习习惯至少有可观察行为，非空泛评价
7L3课次周报检查Math 2/2、English 2/2；不足必须确认原因
8L3月报月测与路线最新信息有明确来源；没有则明确标注缺失

10｜一线督导速查版

培训时只需要记住下面五句话；详细字段由 Skill 自动提示。

1L2日报“把今天学生、时间、任务、核对结果、错题原图、学习习惯和异常一次性发给AI。”
2L2周报“把本周所有L2日报交给AI；缺哪天，只解释为什么缺。”
3L3日报“L2日报全部信息 + 错题证据 + 今天Math/English有没有上专项及老师反馈。”
4L3周报“把本周L3日报交给AI；AI自动检查Math 2次、English 2次是否完成。”
5L3月报“本月日报 + 本月月测 + 最新路线进度 + 必要时上月月报；其余让AI自己汇总。”
!共同底线“不知道就写不知道，没有就写没有；不要为了让报告好看而补数据。”
建议用于 Skill 的统一开场：一线人员只需要说 “我要生成一份L3周报”。Skill负责接管后续信息采集、完整性审核、追问和生成，不要求督导自行记住提示词。
