# 标准作业批改报告接口 v1.0

标准《作业批改报告》是日报的优先上游数据源。

## 批改报告负责
- 逐题判断正确 / 错误 / 待复核；
- 统计总题目数、正确题数、错误题数、正确率；
- 对每一道错题形成：题型、考查能力、学生错误表现、错因、正确/参考答案、关键解析；
- 当原始作业为整页图片时，强制为每道错题生成独立证据裁图；
- 在最终HTML中嵌入错题裁图，并保留机器可读结构化数据。

## L2日报读取
对已有标准批改报告覆盖的作业，L2日报直接读取：
- 总题量 / 正确 / 错误 / 正确率；
- 错题题号与来源；
- 已嵌入的逐题错题裁图；
- 订正状态（如已有）。

L2不得把批改报告中的题型、能力、错因展示到家长日报中，也不得重新批改或重新裁剪同一份作业。

## L3日报读取
对已有标准批改报告覆盖的作业，L3日报直接读取：
- L2所需全部客观数据与错题裁图；
- 题型；
- 考查能力；
- 学生错误表现；
- 错因；
- 正确/参考答案与关键解析（按日报展示需要取用）。

L3不得无故重新分析同一错题；仅在报告缺失关键字段、证据冲突或用户明确要求复核时回到原题重新处理。

## 日报仍保留自主裁图能力
没有经过标准批改报告的材料，例如单词听写、临时小测、督导单独拍摄的一道题等，仍由L2/L3日报按原有保守裁剪协议自行裁图。
