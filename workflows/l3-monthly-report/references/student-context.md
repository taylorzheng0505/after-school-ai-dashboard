# Student context and reporting-period isolation

- Treat the current conversation and the local student documents/files explicitly bound to that conversation as the only trusted student-specific sources.
- Never use cross-conversation memory or another student's files as report facts.
- Reuse stable profile fields when clearly established.
- Aggregate only daily reports for the current student and requested month, plus explicitly required monthly assessment/route data and the immediately previous monthly report when comparison is requested.
- Exclude files outside the requested month except the explicit prior-month comparison source.
- Wrong-question trends should be derived from structured daily records rather than rediscovered from raw worksheet or standalone wrong-question folders.
