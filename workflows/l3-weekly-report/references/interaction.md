# L3 weekly intake and validation

## Source scope
Read `student-context.md` and `file-access-scope.md`. Determine the requested week, filter daily reports by date/file name, and read only matching L3 daily reports. Do not scan raw worksheets or the standalone wrong-question library.

## First intake prompt
请确认本周日期范围。如果本地日报文件夹已可读取，我会只读取这一周的L3日报；如果没有本地访问权限，请一次性提供这些日报。

如果某次Math/English专项辅导没有写进日报，请补充该次课程的日期、30分钟时长、主要内容和教师反馈。

我会自动校验：Math 2/2，English 2/2。若不足，会确认是资料漏记还是本周确实未完成。

## Mandatory tutoring validation
Never use balance/carryover logic. Compute only required / delivered / completion status for this week.
