# L3 daily intake and validation

## Before intake
Read `student-context.md` and `file-access-scope.md`. Reuse stable profile fields. Read only the single latest prior daily report for unfinished long-cycle tasks; ask for today's progress when needed.

## First intake prompt
好的。L3日报会完整继承L2日报。请一次性提供：

1）今天日期、到离校与有效学习时长（姓名/年级/路线已在档案中明确可不重复）。
2）今日全部任务及完成/推进情况；上一份日报中的未结束长期任务我会读取，但必须由你确认今天推进到哪里。
3）今日原始作业/试卷：直接上传，或提供明确文件/文件夹路径。
4）本次批改结果：可以来自你、其他AI、截图、文件、复制文字或本对话前序，只要明确对应今天这批作业；不要因为来源不同而重新批改。若尚未批改并希望我批改，请说明。
5）每道错题可用的补充证据：订正结果、学生卡点、答疑/教师反馈等。有多少给多少，不要求督导自行判断题型/能力/错因。
6）学习过程与习惯、其他异常。
7）今日Math/English专项辅导：分别说明是否上30分钟；如有，提供主要内容和教师反馈；没有请明确写无。

确认错题后，我会从整页原始作业中逐题裁剪证据，再进行L3结构化错题记录。

## Critical/blocking
All L2-daily blocking requirements apply, plus:
- A confirmed L3 wrong question cannot be mapped to original visual evidence.
- A focused-tutoring session occurred but subject/content/teacher feedback is materially missing.
- It is unclear whether Math or English focused tutoring happened today.

## Evidence handling
Use, in priority order: original question evidence -> grading/correction result -> teacher explanation/feedback -> observed student sticking point. Do not fabricate deeper cause when evidence is weak.
