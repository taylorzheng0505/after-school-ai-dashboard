# Student context and date isolation

## Trusted student context
- Treat the current conversation and the local student documents/files explicitly bound to that conversation as the only trusted student-specific sources.
- Do not use facts remembered from another conversation, another student's workspace, or cross-conversation memory as report facts.
- A separate conversation is expected to represent a separate student.

## Stable profile reuse
Stable profile fields may be reused when clearly available: name, grade, school, product level, and current route unless newer information changes them.

## Daily Fresh-State + Continuity Rule
Start each daily report with a blank state for date-specific facts, but read the **single most recent prior daily report** for continuity of unfinished long-cycle tasks only.

May carry forward as a prompt for confirmation:
- ongoing Project / long-cycle assignment
- staged reading or research
- explicitly deferred or unfinished task

Must never be inherited as today's fact without same-day confirmation:
- arrival/departure/effective time
- today's correctness/counts
- today's wrong questions/dictation
- correction status
- today's habit observations
- today's exceptions
- today's focused tutoring

The prior report may tell you what still needs follow-up; it may not tell you what happened today.
