# L2 weekly intake and validation

## Source scope
Read `student-context.md` and `file-access-scope.md`. Determine the requested week, filter daily reports by date/file name, and read only matching L2 daily reports. Do not scan raw worksheets or the standalone wrong-question library.

## First intake prompt
可以。请确认要生成的周报日期范围。如果本地日报文件夹已可读取，我会只读取该日期范围内的L2日报；如果没有本地访问权限，请一次性提供这些日报。

若某个原本应到校的日期没有日报，请说明：A 未到校/请假；B 节假日/机构不营业；C 日报缺失。除此之外无需重新总结本周数据。

## Critical/blocking
- Missing daily report for an unknown-status expected attendance date.
- Daily reports belong to wrong student/week.

## Do not ask again
Do not ask the supervisor to manually total hours, accuracy or error counts when daily reports contain the underlying data.
