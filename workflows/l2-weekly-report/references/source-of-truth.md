# L2/L3 shared source of truth v1.0

Use these rules as the authority whenever older examples or user-supplied legacy templates conflict.

## Shared operating base
- L2 and L3 use the same supervised-study floor process: record attendance/time/route, verify school task list, prepare/print materials, break down and prioritize work, supervise independent execution, use answer keys/AI for basic checking, preserve original wrong-question images before correction, route knowledge questions to roaming teachers, verify corrections before departure.
- Supervisors manage execution; they do not teach subject knowledge.
- School-submission originals must not be marked up by the institution. Use a copy or removable marker/sticker workflow, then have the student correct the official original.
- Preserve original wrong-question images as factual evidence. AI may crop/organize them but must never replace them with OCR-redrawn questions.
- Roaming-teacher quick support is an operational resource, roughly capped around 20 minutes per student/day internally; it is not a promised class allotment.
- Long-cycle projects/reading are tracked by progress for the current day/week, not by misleading task-completion percentages.
- Every daily task carries a deadline. Ordinary same-day homework may use the report date as the deadline when the assignment is clearly due that day; long-cycle/staged tasks must preserve the actual stated deadline. If a long-cycle deadline is genuinely unavailable, show “未明确” rather than inventing a date.
- Weekly dashboards inherit task deadlines from daily data. They must clearly identify unfinished/ongoing tasks at week end, show each deadline, and indicate which items continue into the next week or are already overdue.
- Learning-process/habit comments must describe observable behavior, not vague praise such as “认真/努力”.

## L2
- L2 = learning execution management, not academic teaching/diagnosis.
- L2 wrong-question records: original image + subject + source/question number + correction status. Do not diagnose cause, capability, or targeted remediation.
- L2 has daily and weekly parent dashboards only. No L2 monthly dashboard.
- L2 weekly dashboard is generated from that week's daily dashboards; do not ask the supervisor to resummarize data already present.

## L3
- L3 inherits the complete L2 base.
- L3 adds 4 fixed 30-minute focused tutoring sessions every week: Math 2 + English 2. They must be completed that week. No rollover, no balance, no accumulated remainder.
- Standard grouping is 1v3; launch-stage 1v1/1v2 is allowed if enrollment is low.
- Focused tutoring can include explanation, similar-question practice, transfer/generalization, and reinforcement based on recent wrong questions, repeated weaknesses, quizzes/exams or monthly assessment.
- Each focused tutoring session needs a short teacher feedback record that enters the daily dashboard.
- L3 wrong-question analysis deepens by level: daily = structure a single error; weekly = detect repeated signals; monthly = stable problem map + deeper error chain + teaching action + intervention effect + previous-month comparison.
- Parent-facing analysis must show the final conclusion only. Do not label separate “student/teacher/AI analysis”.
- L3 monthly dashboard needs the current month's mock/diagnostic assessment plus latest route/transition progress as additional inputs. Never invent missing results.

## Parent dashboard visibility
- Parent-facing HTML contains visible information only; do not design hidden backend records inside the HTML.
- Do not mention internal tool mechanics such as “dictation Agent completed this” in parent-facing prose.
