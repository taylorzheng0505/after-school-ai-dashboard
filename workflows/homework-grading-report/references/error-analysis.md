# Wrong-Item Analysis Guide

Every wrong item must include four mandatory analytical fields.

## 1. 题型 / question_type

Describe the response format plus the substantive task when useful.

Examples:
- 数学：`单项选择题｜古典概型与组合计数`
- 数学：`填空题｜二项式展开常数项`
- 英语：`阅读理解｜细节理解与同义改写`
- 英语：`语法填空｜非谓语动词`
- 英语：`写作｜论证段落组织`
- 历史：`材料分析题｜原因解释与史料证据`
- 科学：`实验题｜变量控制与实验设计`
- 科学：`数据题｜图表读取与趋势解释`
- 语文：`阅读理解｜概括与证据提取`

Do not write only `选择题`, `填空题`, or `简答题` when a more informative type is identifiable.

## 2. 考查能力 / tested_ability

Describe the student operation required by the task. This is not just the topic name.

Useful ability families:
- 读取/定位关键信息
- 理解题干条件与限制
- 同义改写识别
- 概念区分与概念迁移
- 数学建模/数量关系转化
- 公式/规则选择
- 多步推理与推理链保持
- 符号、单位、计算准确性
- 图表/数据解读
- 变量控制与实验设计
- 证据选择与证据强度判断
- 因果解释
- 比较与归纳
- 史料/文本来源评价
- 观点推断，避免过度推断
- 书面组织、论证与表达
- 拼写/词形/语法检索

Use 1–3 concise abilities, not a long generic list.

## 3. 学生错误表现 / error_manifestation

Only state observable facts.

Good:
- `选择 C(1/3)，正确答案为 B(2/3)`
- `定位到了相关段落，但把 “hardly worthwhile” 理解成 “extremely risky”`
- `列出了自变量和因变量，但没有控制温度这一额外变量`
- `答案列出两个原因，但缺少材料中的经济因素证据`

Bad:
- `学生基础差`
- `学生不认真`
- `能力很弱`

## 4. 错因 / error_cause

Explain the error mechanism, not a personality trait.

Preferred mechanism families:
- 概念边界混淆
- 题干条件漏读/误读
- 词汇或术语理解错误
- 方法选择错误
- 分类/计数遗漏或重复
- 推理链中断
- 把相关性当因果
- 证据强度判断错误/过度推断
- 单位、符号、指数、计算过程错误
- 公式/语法规则调用错误
- 答案组织不完整
- 证据使用不足
- 关键步骤遗漏

### Avoid overclaiming

Do not write `不会`, `完全没掌握`, `粗心`, `基础差` unless the evidence genuinely supports that statement.

If only the final response is visible:
- use `从当前答案看，更可能是...`
- or `当前表现更符合...`
- or `仅凭最终答案无法完全区分A/B，但更可能...`

### “粗心” rule

Use `计算/抄写/符号失误` instead of generic `粗心` whenever possible.
Only call an error a simple slip when the student's method is demonstrably correct and the mistake is isolated.

## 5. Cross-subject examples

### Math
题型：`填空题｜二项式定理常数项`
考查能力：`通项公式调用；指数条件求解；符号与计算准确性`
错误表现：`填写250，正确答案240`
错因：`解题路径可成立，但最后15×16计算错误；若学生过程可见且前序步骤正确，可判为计算失误。`

### English reading
题型：`阅读理解｜Inference`
考查能力：`理解程度副词；基于文本证据控制推断强度`
错误表现：`将“hardly worthwhile”推成“extremely risky”`
错因：`把“收益不足”误等同于“风险极高”，推断强度超过原文证据。`

### History
题型：`材料分析题｜原因解释`
考查能力：`从材料提取证据；建立原因与结论之间的因果链`
错误表现：`只写政治原因，漏掉材料明确给出的经济条件`
错因：`材料证据提取不完整，导致原因分类遗漏。`

### Science
题型：`实验题｜控制变量`
考查能力：`识别自变量/因变量；控制干扰变量`
错误表现：`改变光照的同时也改变了温度`
错因：`没有保持除自变量外的关键条件一致，导致实验无法单独检验光照效应。`
